1. Sumário executivo

O GuardKids WP é uma plataforma de controle parental web premium empacotada como um único plugin WordPress. Reúne um painel dos pais (SPA React), um painel infantil instalável (PWA) e um navegador seguro, sobre uma API REST autenticada. Além do controle de tela e navegação, cobre geolocalização com zonas seguras, gamificação (medalhas, missões, recompensas), uma trilha educacional (Academy) com quiz e insights de IA para o responsável, segurança de conta (2FA, PIN, sessões), privacidade/LGPD e o app companheiro Android (Companion).

Estado geral: SAUDÁVEL, sem entrega represada O código está estável e com 1.281 testes automatizados 100% verdes (executados nesta análise). O master local está sincronizado com o origin e em paridade com produção (v1.41.0 / DB v27). As últimas grandes entregas — Localização Inteligente por endereço e a plataforma Academy completa (Ondas 1 a 5, incluindo os insights de IA) — já estão publicadas.
Ação recomendada imediata Não há release pendente. O maior valor agora é de engenharia de plataforma: automatizar o deploy (hoje SSH manual) via CI, adicionar E2E (Playwright) e versionar/atualizar a documentação (README e estes relatórios).

3. Arquitetura

A arquitetura é em camadas dentro de um plugin único. O núcleo PHP expõe uma API REST versionada; os dois frontends React consomem essa API e são servidos pelo próprio WordPress em rotas dedicadas. Toda a configuração vive em tabelas próprias (prefixo wp_guardkids_*), com versionamento de schema por migrations idempotentes.

4. Funcionalidades

Painel dos pais (app-parent)

  • Dashboard — visão geral e status online dos filhos (atualização automática via Web Push).
  • Filhos — cadastro, pareamento e gestão de dispositivos.
  • Limites de tempo — limite diário e por dia da semana.
  • Regras de sites — bloqueio/liberação por site e categoria.
  • Modo de proteção — perfis de restrição.
  • Localização — mapa, local atual e Locais/Zonas Seguras (geofencing + endereço).
  • Aprovações & pedidos — fila de solicitações da criança.
  • Conteúdo — dashboard de moderação e biblioteca.
  • Academy — trilhas educacionais e progresso das aulas dos filhos.
  • Gamificação — medalhas, missões e recompensas/loja.
  • Relatórios — uso e eventos, com insights de IA (Pro) resumindo em linguagem natural.
  • Configurações — conta, segurança (2FA/PIN/sessões), preferências.
  • Licença & upgrade — ativação Pro e planos.

Painel infantil (app-child · PWA)

  • Home e Mundo — hub gamificado da criança.
  • Academy — trilha de aulas com quiz que rende XP ao ser aprovado.
  • Navegador seguro — navegação filtrada, tela de bloqueio.
  • Pedidos — solicitar acesso/tempo ao responsável.
  • Loja & Avatar — resgate de recompensas e personalização.
  • Localização — envio de posição e Locais.
  • Alertas e pareamento (PairScreen) por token.

Plataforma transversal

  • Segurança da conta: 2FA TOTP + códigos de recuperação, PIN infantil, sessões ativas, auto-logout.
  • Privacidade/LGPD: exportar e apagar dados; insights de IA usam dados pseudonimizados.
  • Notificações: e-mail (resumos diário/semanal) e Web Push (tela atualiza sozinha).
  • GuardKids Companion: telemetria via app Android (tokens endurecidos).
  • Licenciamento Pro: gate de recursos (incl. ai_insights) com verificação e cache de revogação.
